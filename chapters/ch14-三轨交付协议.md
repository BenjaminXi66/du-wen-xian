# Ch14 三轨交付协议（v1.5.0 重写 —— 本技能的交付形态层）

> v1.4 曾规定"双轨同出"（逐段领读 + 结构化报告一次给全）。真实使用中两者相加超出单轮输出容量，且用户往往只需要其中之一。**v1.5 改为三选一询问制**：先出菜单，用户报数字，一次一轨；轨间用段落锚点 PID 衔接，已输出的内容不重复。

---

## 14.0 一句话规则

> **三条功能轨（1 结构化速览 / 2 通读带读 / 3 质量评估），每轮只执行一条；用户未指明时先出菜单等数字，指明时直接执行；轨间用 PID 衔接，已读内容不重复输出。**

---

## 14.1 询问门（ask-first gate）

**触发条件**：用户提供了文献（PDF/文本/DOI/引文），但话语中没有可映射到某条轨的明确信号。

**必须做的动作**：原样输出标准菜单（措辞可微调，三行功能与"输入数字"提示不可省）：

> 本 skill 具有三条功能：
> **1、输出结构化的结果**——快速了解文章及作者信息（导语 + 身份卡 + 核心主张 + 论证链条 + 发现 + 术语 + 800 字提炼）
> **2、通读论文**——带读摘要、关键段落和结论（逐段"原文 + 译文 + 解析"领读）
> **3、评估论文质量**——按论文类型路由评审框架，输出总评 + 检查表 + 红线单 + 修改优先级（P0/P1/P2）
>
> 由于上下文长度限制，无法一次性输出三个结果，因此由你决定这次先看哪个：**输入数字（1 / 2 / 3）得到相应回答**。也可连选（如"2，然后 3"），将分轮逐轨交付。

**然后停止**。不得在菜单后附"我先默认给你轨 1"之类的预览，不得边问边做。

**豁免（指明即执行，不再发菜单）**：

| 用户信号 | 执行轨 |
|---|---|
| "通读 / 带我读 / 领读 / 逐段讲 / 读摘要和关键段落 / 原文+译文" | 轨 2 |
| "结构化 / 速览 / 快速了解 / 概览 / 作者信息 / 这篇文章讲什么" | 轨 1 |
| "评审 / 审稿 / 打分 / 研判质量 / 写审稿意见 / 修改意见" | 轨 3 |
| 明确连选（"1 和 3"、"先 2 再 3"） | 本轮执行先提到的那条，轨末提示输入下一轨数字 |
| "只看方法 / 只看理论框架 / 只回答 X" | 按最近轨次执行，只覆盖相关部分，**开头声明省略了哪些部分** |

**边界情形**：
- "帮我看看这篇论文"（含糊）→ 属询问门触发条件，出菜单。
- "这篇能投 XX 期刊吗"→ 映射轨 3（质量评估 + 评审者模拟）。
- "这篇跟我手头研究有什么关系"→ 映射轨 1（重点出 §0 导语、§11 资产对接），并声明省略项。
- 用户报的数字不在 1–3 → 礼貌重发菜单，不得自行解释成其他轨。

---

## 14.2 一次一轨（合并禁令）

1. **同一轮禁止合并两条及以上轨**——哪怕内容放得下。用户说"都要"时，回答："分轮给你，先出哪条？请报数字。"（或按用户已给顺序先出第一条）。
2. 一轨内部的完整性不受影响：轨 1 照 ch10 全模板、轨 2 照全文领读协议、轨 3 照 ch13 骨架，**不得因"只出一轨"而砍各轨内部的必要节**。
3. 单轨仍然超长 → 按 14.6 分册，附分册计划表。

---

## 14.3 段落锚点 PID（三轨公共资产）

PID 格式 `<部分字母>-<两位序号>`，写作 `[R-03 · p.812]`：

| 字母 | 部分 | 备注 |
|---|---|---|
| `A` | 摘要 | 轨 2 中 **100% 逐段全读** |
| `I` | 引言 | |
| `L` | 文献回顾 | |
| `M` | 研究设计 | |
| `R` | 实证分析 | |
| `D` | 讨论与结论 | |
| `O` | 其他（承担论证功能的脚注/图表说明/附录） | 须注明入选理由 |

规则：
1. PID 一经分配**不重编号**；跨轮续接，不从头再来。
2. 原文没有某部分 → PID 全空，注明"原文无此部分"。
3. **PID 是轨间衔接件**：轨 2 领读时必打；轨 1 / 轨 3 的事后引用一律 `→[PID]` 回指，不重抄原文；轨 3 的评审证据挂 PID 或页码。

## 14.4 各轨章程速览

| | 轨 1 结构化速览 | 轨 2 通读带读 | 轨 3 质量评估 |
|---|---|---|---|
| 章程 | ch10 模板（0–16 节） | SKILL.md"全文领读协议" | ch13（§13.0 路由 → §13.6.2 骨架） |
| 核心产出 | 导语+身份卡+主张+论证链+发现+术语+800 字提炼 | 摘要全读 + 关键段落三段式 | 总评+检查表+红线单+P0/P1/P2 |
| 画像卡 | 必做（资产对接用） | 必做（解析详略校准用） | 可跳过（除非用户要资产对接） |
| 原文引语 | 关键处引语（标页码） | 逐字引语为轨之根本 | 每条批评挂位置 |
| 位置标注 | 页码或 PID | PID（必打） | 页码或 PID |
| 收尾 | 覆盖自查表 + 切换提示行 | PID 台账 + 切换提示行 | 覆盖自查表 + 切换提示行 |

**切换提示行（三轨通用，固定文案）**：
`——本轨完成。输入 1 / 2 / 3 可切换其他视角；已读内容不会重复输出，轨 2 的段落锚点会被轨 1 / 轨 3 直接引用。——`

---

## 14.5 跨轮衔接协议（切轨时做什么）

1. **轨 2 → 轨 1**：结构化速览的"位置"列直接 `→[PID]` 回指已领读段落；用户想看某段原文时引 PID 处原文（短引），不重新领读。
2. **轨 2 → 轨 3**：评审证据挂 PID（`→[R-05, p.815]`）；轨 2 的 PID 台账就是评审的"落实位置索引"。
3. **轨 1 → 轨 2**：领读不再重复导语（除非用户要求）；直接从摘要开始逐段讲。
4. **轨 1 / 轨 3 → 轨 3 / 轨 1**：已完成的结构化信息（身份卡、论证链）不重复输出，评审报告直接引用其节号（"见轨 1 §5"）。
5. **会话跨天/上下文丢失**：PID 台账不在上下文时，按需重新定位页码，不臆造 PID。

---

## 14.6 长文档分册（单轨内部的容量管理）

1. 分册前先出**分册计划表**（各册覆盖的 PID 区间或章节），一次给全。
2. 每册末尾：本册已完成清单 + 尚未覆盖清单（"待续"）。
3. 最后一册给该轨的收尾件（自查表 / PID 台账 / 切换提示行）。
4. **禁止事项**：禁止交"节选版/预览版"当完整轨；禁止"下次再补"作为收尾；禁止跨册混入其他轨的内容。

---

## 14.7 违规形态（交付前自查排除）

| 违规形态 | 表现 | 处置 |
|---|---|---|
| **三合一** | 一轮内同时给结构化+领读+评审 | 拆轮：本轮保留最贴合用户话语的一条，其余提示报数字 |
| **不问就做** | 用户没指明轨次，直接开做某一轨 | 停下，发菜单等数字；已做部分可保留但须声明 |
| **假菜单** | 发了菜单却接着自行输出内容 | 菜单后必须停止 |
| **轨内缺斤短两** | 借口"只出一轨"砍掉轨内必要节（如轨 1 没有导语、轨 2 没有译文） | 按各轨章程补全；实在超长走分册 |
| **跨轨重复抄写** | 切轨后重抄大段原文 | 改为 `→[PID]` 回指 |
| **幽灵 PID** | 回指了从未领读过的 PID | 重新定位页码或如实说明"该段未领读" |

## 14.8 各轨自查清单（收尾前过一遍）

**通用**：
- [ ] 本轮只出了一条轨？
- [ ] 菜单仅在"用户未指明"时出现，且发出后停止了？
- [ ] 切换提示行已附上？
- [ ] 零幻觉 / 两层隔离（铁律一、四）未被破坏？

**轨 1**：16 节逐节点名无缺节；术语表 5–8 条；资产对接个性化；800 字提炼在 700–900 字。
**轨 2**：摘要段数 N = A 轨条数；五大结构部分各 ≥1 段（或注明原文无此部分）；每段三字段齐全、译文无摘译；PID 台账完整。
**轨 3**：框架逐条点名"已查/原文未涉及"；每条批评有位置；P0/P1/P2 分级；打分口径按 ch13.6.3。
