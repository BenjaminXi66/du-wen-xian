# Ch04 定量论文精读：十一条读法与表格解读

来源：Greta Krippner《How to Read a (Quantitative) Journal Article》（为 Sociology 210 编写，ASA 教学材料，2000；示例论文为 Jeremy Freese, Brian Powell, and Lala Carr Steelman, "Rebel Without Cause or Effect: Birth Order and Social Attitudes," *American Sociological Review* 64 (1999): 207–231）。

## Core Idea
定量论文遵从固定公式，读它有一套几乎机械的次序：先定问题与论战对象，再锁定变量与测量，然后**沿表格逐模型解读**——显著性、方向、控制、稳健性、交互效应，一步都不能跳。**表格里出现的数字几乎都会在正文中被讨论，所以正文与表格必须对照读：正文会告诉你表里哪些数字重要。**

---

## 定量论文的标准结构

定量文章有基本相同的结构：
1. **引言**：提出问题、预览论文目标
2. **理论部分**：描述与所处理问题相关的文献
3. **数据部分**：描述分析所用数据来源
4. **分析或结果部分**：解释所做各种统计检验、呈现发现
5. **讨论或结论部分**：把主要发现与理论文献重新连接

---

## 十一条读法

**1. 定量论文遵循公式。**（见上结构）

**2. 表格里的东西几乎都会在正文讨论——正文与表格对照读。** 文本会提示你表格中哪些数字重要。

**3. 第一个任务：识别研究问题，并找出作者在跟谁争论。** 问题通常在前一两页就清楚。示例论文中，作者把问题定位为检验出生次序对各种社会态度（包括保守主义）的效应（pp.208–209）。**除识别问题本身外，还要确定作者在反对谁或什么——即作者把自己置于既有论战的什么位置**：Freese 等人反对的是 Sulloway——他们承认 Sulloway 是第一个研究出生次序与社会态度关系的人、贡献重大（p.208），但批评他暗示出生次序比标准社会学变量（性别、种族、阶级、年龄、兄弟姐妹数）更重要。

**4. 识别相关变量及其测量方式。** 主自变量是出生次序，以二分法测量（受访者为头胎 / 非头胎）；因变量"社会态度"用六个具体测量来操作化：政治自我认同、对自由派社会运动的反对、种族与性别上的保守观点、对既有权威的支持、"强硬心态"（tough mindedness）；每个测量再被进一步操作化。例如以"你作为一个美国人有多自豪？"来测量"对既有权威的支持"这一变量（p.215）。

**5. Results 是文章的核心，也最难读——先搞懂变量编码。** 必须先弄清**变量如何编码：正系数与负系数各意味着什么**。示例论文（p.215）的测量按"正系数与头胎更保守的假设一致"的方式编码，因此负系数不支持假设。第一个模型中有两个显著系数（p.216）：**"显著"意味着观察到的效应强到足以把偶然作为解释排除掉**；显著性以星号标示（多颗星意味着更有把握该观察不是偶然产生的）。此例中：第一个显著系数为正 → 头胎者更可能投 Bush，支持假设；而"对犯罪强硬"测量上的显著负系数 → 头胎者比晚出生者更不可能对犯罪强硬，**与假设矛盾**。综合看：24 个测量中只有 2 个显著，其中只有 1 个支持假设——"第一个模型并不太支持出生次序理论"。

**6. 理解"多个模型"的作用。** 指定不同模型让研究者有不止一次机会辨识数据中的模式。Freese 等人从其他研究知道性别、年龄、种族、父母教育与兄弟姐妹数与社会态度相关，所以也许出生次序与社会保守态度真有关系、只是被这些变量遮蔽——处理办法是把人口学变量作为**控制变量**引入，即**把它们保持恒定以分离出生次序的效应**（Model 2）。结果仍然没找到多少关系。

**7. 继续加控制（Model 3、Model 4）。** 追加的控制指定其他已知与社会态度相关的因素——父母职业声望、父母婚姻状况、16 岁前失去父母、童年宗教、成长地区（Model 3）；以及受访者教育与职业声望（Model 4）。但在 Model 3 与 Model 4 中，和 Model 2 一样：24 个测量中只有 3 个显著，而且方向还不对（**由于编码方式，负数与"头胎更保守"的假设相矛盾**）。

**8. 注意"控制变量转正"的策略比较。** Freese 等人接着（pp.218–219）把原本作为控制的变量——性别、年龄、种族、父母教育、兄弟姐妹数——与出生次序的效应逐一比较。注意此时（Table 2）这些变量**不再是控制变量**：它们不再被保持恒定，而是被允许变动，以便与因变量的变异建立联系。结果显示这些变量作为社会态度的预测因子远比出生次序有力（每个变量至少 12 个测量显著）。但看显著测量的模式：只有年龄是一致的，其他自变量内部充满矛盾——例如父母受教育程度高的受访者对社会态度的测量更自由，但同时也更可能自称共和党人而非民主党人。作者由此得出：**"保守"这类标签可能并未捕捉一组统一的价值观**，出生次序理论的支持者也许靠的是**在现实世界中几乎无从着力的模糊概念**。

**9. 识别稳健性检验（robustness checks）。** 主分析之后，研究者通常会做若干额外检验以确立发现的稳健性——确保结果不是以特定方式操纵数据的产物。示例论文用**一个包含家庭内部数据的不同数据集**、以及**来自 GSS 的更广泛的社会态度测量**来检验稳健性，两项检验都不改变结果——这增加了他们对结果正确的信心。

**10. 识别交互效应检验（interaction effect）。** 想法是：某变量的作用方式受另一变量存在与否的影响。示例论文检验的交互是出生次序与子女间隔：理论认为出生次序对社会态度的效应在相邻子女间隔为 2–5 年时最明显。同样，数据没有提供这方面的证据。

**11. 解读回归表的两问总结。** 对 Table 1、Table 2 这类表格，要考虑两件事：
1. 有没有变量显著？
2. 若显著，该变量对因变量的作用方向是否与预测一致？

## 读表格时的完整问题链（由十一条归纳）

按顺序对每一篇定量论文自问：
1. 研究问题是什么？作者在反对谁？
2. 自变量、因变量分别是什么？如何操作化？
3. 编码方向：正/负系数各支持什么？
4. 哪些系数带星号？几颗星？
5. 显著的有几个？方向对的有几个？（示例：2/24、3/24 的判读）
6. 模型之间加了什么控制？加了控制后效应是否缩小/消失？
7. 有没有"控制变量转自变量"的效应大小比较？
8. 有没有稳健性检验（换数据集/换测量）？
9. 有没有交互效应检验？
10. 作者据此对理论做出什么判断（支持/削弱/质疑概念本身）？

## 术语表（原文 Vocabulary 部分，定义照录）

| 术语 | 定义 |
|---|---|
| **Bivariate Relationship（双变量关系）** | 在孤立于其他因素的情况下考察的两个变量之间的关系。示例论文首先考察了出生次序与社会态度各测量之间的双变量关系（pp.215–217）。 |
| **Control Variable（控制变量）** | 被保持恒定的变量，以便更清楚地观察你所关心的第三个变量对因变量的效应。通常通过只选取在控制变量上相同的个体来实现（如只研究男性以控制性别）。**每当一个变量被保持恒定，该变量就无法解释因变量的变异，你也就把它的效应从考察中排除了。**这不是说该变量与因变量没有关系，只是那不是你在研究的关系。保持变量恒定是通过排除当前不关心、但否则可能解释现象一部分的变量来简化复杂社会情境的手段。 |
| **Correlate（相关物）** | 与另一变量存在关系的变量。 |
| **Correlation（相关）** | 两个变量之间关系的强度与方向的度量，取值 -1.00 到 1.00：正（直接关联，同向变动）或负（反向关联）。相关可以是强的（同卵双胞胎身高 0.95）或弱的（1988 年 25–34 岁男性教育与收入 0.34）。**相关为 0 表示没有关系。注意：相关不蕴含因果，因为它不告诉我们谁是因谁是果。** |
| **Dependent Variable（因变量）** | 研究者试图解释或预测的变量；一个或多个自变量的假定结果。 |
| **Dichotomous Variable（二分变量）** | 只能取两个值的变量（是/否）。示例论文中出生次序是二分的：受访者是头胎或不是。 |
| **Explanatory Variable（解释变量）** | 自变量的另一种说法——被假定为因变量（结果变量）之原因的变量。 |
| **Independent Variable（自变量）** | 因变量的假定原因。 |
| **Interaction Effect（交互效应）** | 一个自变量对因变量的效应随另一个自变量的取值或水平而变化的结果；两变量共同作用的效应不同于各自单独的效应。 |
| **Multivariate Relationship（多变量关系）** | 同时考虑多个（两个以上）变量的关系。 |
| **Null Hypothesis（虚无假设/零假设）** | 你所检验的变量之间没有关系的假设。示例论文谈"null results"时，指其数据提供的"出生次序对社会态度无效应"的证据（p.217）。 |
| **Operationalization（操作化）** | 对把单位归入某变量类别所需的研究操作或程序的详细描述。具体说：抽象概念（用"社会态度"这样的变量来代表）如何被测量？示例论文中"对自由派社会运动的反对"是"社会态度"概念的一种操作化（p.214）。 |
| **Population（总体）** | 某个被界定类别的人、物或事件的总成员；也称 universe。用 GSS 数据的示例论文中，总体是美国所有非收容机构、说英语的成年人（p.212）。 |
| **Regression（回归）** | 研究变量间线性关系的统计技术；可考察双变量关系（简单回归）或多变量关系（多元回归）。 |
| **Regression Coefficient（回归系数）** | 表达一个变量对另一个变量之效应的方式。在特定条件下，它有一个相当直截了当的解释：**表示自变量每变动一个单位，因变量变化多少**。 |
| **Robustness（稳健性）** | 稳健的结果是在范围广泛的不同检验下都站得住的结果：一种方式做统计检验得到该结果，换一种方式得到相同结果，换数据仍得相同结果——那么这个发现是稳健的。 |
| **Sample（样本）** | 为研究而从总体中选出的案例（通常是个体）子集；也用于指明选择方法——随机样本或全概率样本指每个具有所需属性的个体被选中的概率相等。样本可为回答特定问题而进一步受限（如测量种族平等信念时只限白人，以保证与被批评研究【用全白样本】的可比性）。 |
| **Significance（显著性）** | 若某变量的效应足够强，以至于我们可以把"偶然"作为该观察关系的解释排除掉，则它在统计上显著。 |
| **Standard Deviation（标准差）** | 一组观察值的变异程度的度量，也称方差，指示观察值围绕均值的平均"散布"。紧贴均值聚集的观察值方差低，广泛分散的方差高。 |

> 原文注明：许多定义基于 Singleton, Straits, and Straits, 1993, *Approaches to Social Research*。

## Mental Models
- **正文是表格的导览**：不要单独啃表；正文在告诉读者"这张表里哪个数字值得看"。
- **24 个测量里 2 个显著、其中 1 个方向还反了——这种"比例感"是读表的肌肉记忆**：显著的少 + 方向混乱 = 不支持假设。
- **模型的堆叠是为了分离效应**：看到 Model 2、3、4，先问每个模型加入了什么控制、核心变量的系数如何变化。
- **控制变量转正**是检验"核心变量是否真的特别"的对照手段：如果原本的控制变量每个都 12+/24 显著，而核心变量只有 2–3/24 显著，理论地位一目了然。
- **概念本身的测量合法性可以被质疑**（Freese 等对"保守"标签的处理）：统计做得再对，概念外延模糊也会掏空结论——这正是 POC 的经典落点。

## Anti-patterns
- **跳过方法与变量定义直奔结论**。
- **不查编码方向就解读系数正负**。
- **只看"有没有显著"，不看方向是否与假设一致**（原文两条之一）。
- **忽略稳健性与交互效应检验**——它们是作者自信心的来源，也是可攻击点。
- **把"作者承认某个测量的模糊性"读成"作者自我批评的谦虚"而不继续追问**：模糊概念+显著结果，可能整座楼都建在沙滩上。

## Key Takeaways
1. 定量读文的次序：问题与论战 → 变量与操作化 → 编码方向 → 显著性与方向 → 模型演进 → 控制转正比较 → 稳健性 → 交互效应。
2. 原文给出的判读总纲就两条：**是否显著；若显著，方向是否如预测**。
3. 每个模型都要问"这次加了什么控制、核心系数怎么动了"。
4. 换数据集、换测量的稳健性检验是结果可信度的分水岭。
5. 概念测量（operationalization）是否准确反映目标概念，是 POC 的第一落点。
