# Ch10 精读报告模板与执行协议

本章是本技能的**交付标准**。每一次"读文献"任务最终产出的就是按本模板填写的报告。模板设计对应三条铁律（见 SKILL.md）：零幻觉、信息无损精读、类型对路。

---

## 一、执行协议（按序执行，不得跳步）

1. **确认输入**：拿到文档（PDF/文本/引文信息）后，先确认可提取的正文。若为扫描件且无可用文字层，须先做 OCR 或如实报告"无法提取正文"，**不得凭标题与常识编造内容**。
2. **研究者画像扫描**（ch12 §1）：conversation_search 归纳使用者研究线，产出画像卡。
3. **通读一遍原文**（或分块读完），不做笔记，只建立整体感。**分块读时必须读到文末，不得只读开头就动笔。**
4. **结构读**（ch01）：章节功能地图 + 结构读四问。
5. **生成导读**（ch12 §2）：**读完标题、开始读摘要之前**交付导语（知识网络定位 + 作者谱系）。全程纯文本输出，不生成思维导图或任何图片。
6. **三遍定位**（ch01）：五 C → 图表与标记 → 关键部分虚拟重实现。
7. **逐段精读**（ch02 + SKILL.md 精读顺序）：按"标题→摘要→正文关键段落"顺序，每段"原文+译文+解析"三段式，并打阅读密码（WTD/SPL/CPL/GAP/RAT/ROF/RCL/RTC/WTDD/RFW/POC/MOP/RPP/WIL）；随手收集术语。
8. **术语中英文对照与分析**（ch12 §4）：汇总为面向零背景读者的对照表。
9. **论证解剖**（ch03）：五要素逐项落位；定量加 ch04 十一条；质性加 ch05 十问。
10. **填写报告**（本章模板）。
11. **800 字提炼 + 思考问题**（ch12 §5）。
12. **覆盖自查**（模板第 16 节）——自查不过，报告不算完成。

---

## 二、精读报告模板（全文照此结构输出）

- 篇幅：页数 / 字数 / 章节数

## 2. 核心主张（Claim）

## 4. 文献对话位置（Shon 密码链）

## 6. 数据与方法

- 数据来源与样本（总体/样本/抽样方式）：
- 自变量与操作化（逐个）：
- 因变量与操作化（逐个）：
- 编码方向（正/负系数各意味着什么）：
- 模型序列（Model 1…n 各加了什么控制）：

## 三、填写规则（硬性）

1. **每个内容栏位优先原文引语**（加引号 + 页码）；引语必须逐字，包括标点与限定词（"可能""一些""大多数"不得省略——参见 ch03 9.4.2 对模糊词的警戒）。
2. **转述必须真正重排句式与语序**（ch09 14.6.3 手指滑句检测法），并在报告中标明"转述"。
3. **数字零加工**：样本量、系数、星号数、页码区间、年份区间、词数——照抄。需要换算时（如把英文短语译成中文），保留原文并在括号内给出译文，**注明"译"**。
4. **"作者没写"本身就是信息**：如原文没有讨论信度，第 6 节写"未讨论信度（CASP Q9 无对应内容）"，而不是替作者补一段。
5. **密码栏位允许为空**：有的文章确实没有明确的 SPL 或 RFW；空栏照实写"无"，并在备注中说明"该文未设文献综述节"之类的事实。
6. **推论栏与事实栏物理隔离**：报告正文的 1–9、13、16 节只允许出现文本内可验证的内容；第 0 节（导读）受铁律四约束（外部信息须核实并标注）；第 12 节允许推论但必须挂依据。
7. **报告语言**：中文为主；关键术语、密码缩写、直接引语保留原文语言。
8. **长度不设上限**：铁律二（信息无损）优先于简洁；但**不得用重复或注水凑长度**。

## 四、常见文档形态的处理

| 形态 | 处理 |
|---|---|
| 可提取文字层的 PDF/文本 | 直接按协议执行 |
| 扫描 PDF（乱码/无文字层） | 先 OCR（逐页），报告"文献身份卡"中注明"依据 OCR 文本，可能有识别误差"；OCR 产生的错字在引语处标注 [OCR 可能误差] |
| 专著 | 按 ch08 执行：先结构读全书（目录/索引/序言/结论），再按章节分层精读；报告第 13 节逐章点名 |
| 只有引文信息（无原文） | **不得产出"精读报告"**。只可产出：来源定位建议（ch06）与"待获取清单"；并明确告知用户缺原文、无法精读 |
| 多篇文献批量任务 | 每篇独立一份报告；另附跨文献的 SPL/CPL 主题归并表（RCOS 用法，ch02） |

## 五、质量红线（交付前自查）

- [ ] 报告中每一条事实性陈述，我都能指出它在原文的位置吗？（导读层第 0 节除外，但须核实并标注）
- [ ] 有没有任何一句是"听起来对所以写上了"而原文没有的？（有 → 删或移入第 12 节挂依据）
- [ ] 有没有任何对作者动机、立场、策略的揣测？（有 → 删）
- [ ] 覆盖自查表是否逐节点名、无一遗漏？
- [ ] 数字与引语是否与原文逐字一致？
- [ ] "待核"项是否如实列出，而不是被流畅表述掩盖？
