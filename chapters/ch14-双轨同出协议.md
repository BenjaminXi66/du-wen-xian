# Ch14 双轨同出协议（v1.4.0 新增 —— 本技能的**默认交付形态**）

本章解决的问题：v1.3 及以前，"带我通读摘要和关键段落"会得到一段流畅的逐段领读却没有结构化结论；"输出结构化结果"会得到一叠表格却没有可供核验的原文与译文。两者本应是**同一份报告的两条轨道**，但旧版把它们写成两套并列的交付物，于是每次只能二选一。

本章的解法不是"多写一遍"，而是**一次成文、段落级绑定**：领读轨（甲轨）是唯一的原文出处，结构轨（乙轨）以段落锚点回指甲轨，绝不重复抄述。这样两条轨道同时在、且总量不会翻倍。

---

## 14.0 一句话规则

> **每一次"读文献"交付，必须同时含甲轨（逐段领读：原文→译文→解析）与乙轨（结构化报告：16 节骨架），且乙轨每一格都能回指甲轨的具体段落锚点。缺任一轨，报告视为未完成。**

---

## 14.1 为什么旧版会二选一（认因，便于自查）

| 旧版结构性缺口 | 后果 |
|---|---|
| ch10 报告模板的 16 节里**没有"逐段领读正文"这个槽位** | 照模板填 → 没有领读 |
| 领读协议把三段式写成"输出方式"（独立模块） | 照领读协议写 → 没有结构化 |
| 旧自查表只查"领读 5 条"与"覆盖自查表"，**没有双轨齐备项** | 缺一轨也能通过自查 |
| 评审模式写成"**切换到**评审模式" | 模式被理解为互斥开关，叠加关系被抹掉 |
| 输出偏长时模型自作主张"二选一" | 长文档尤其容易丢掉乙轨 |

**v1.4 的对策**：给两者一个共享的编号系统（PID），并设"反向覆盖门"——乙轨缺锚点就必须回甲轨补读，使"要结构化"在机制上自动强制"要通读"。

---

## 14.2 段落锚点编号系统（PID）

PID 是两条轨道之间的唯一连接件。格式：`<部分字母>-<两位序号>`，序号按该部分在原文中的**物理顺序**递增，从 01 起。

| 部分字母 | 对应部分 | 覆盖要求 |
|---|---|---|
| `A` | 摘要（Abstract） | **100% 逐段全读**，不得挑选、不得"摘要要点"式概括 |
| `I` | 引言（研究背景与问题的提出） | 必选段 + 该部分其余段落视需要 |
| `L` | 文献回顾 | 必选段 |
| `M` | 研究设计（数据/案例/方法） | 必选段 |
| `R` | 实证分析（结果/发现） | 必选段 + 图表文字解读 |
| `D` | 讨论与结论 | 必选段 |
| `O` | 其他（关键脚注、附录、图表说明中承担论证功能者） | 按需，须注明"为何入选" |

**PID 书写规范**：
1. 每条锚点写成 `[R-03 · p.812]`——PID + 原文页码/位置，两者不可分。
2. 一个 PID 只对应**原文的一个连续段落**（或一个逻辑完整的小节）。不得把两段合并成一条，也不得把一段拆成多条（除非该段跨页且论证功能明显不同，此时拆为 `R-03a/R-03b`）。
3. PID 一经分配**不得重编号**。分册交付时后续册的编号必须接续，不得从头再来。
4. 原文没有某部分 → 该部分 PID 全空，在乙轨与自查表中注明"原文无此部分"，**不得借用其他部分的 PID 顶替**。

## 14.3 甲轨：逐段领读（原文 → 译文 → 解析）

### 14.3.1 单条锚点的固定格式（照此输出，字段不得省略）

```
#### [R-03 · p.812] 结果部分第 2 段
- **原文**：「逐字引语，含标点、限定词与原文强调」（p.812）
- **译文**：完整中译，不摘译、不跳句、不省略括号内容；专有名词首次出现给英文原文
- **解析**：这段在做什么（论证功能）｜关键术语（→ 术语表第 n 条）｜与前后段的关系｜读者须注意之处
- **密码**：ROF
- **结构落点**：乙轨 §7-R2 ／ §11-POC1 ／ §13-句2
```

**字段纪律**：
- **原文**：逐字；外语原文与中译分开给，不得只给中译。抽取残缺、OCR 疑误、页码不明，就地标 `[待核：<具体不确定什么>]`（铁律一）。
- **译文**：完整中译。允许在译文中加方括号补出原文省略的主语（须标"译按"），**不允许摘译、不允许"以下大意"、不允许用要点代替句子**。
- **解析**：写清三件事——(a) 这段履行什么论证功能（配阅读密码）；(b) 关键术语与概念在此处如何被使用；(c) 它与前后段、与全文 claim 的关系。解析详略按 ch12 画像卡校准（使用者陌生的传统多解释，专长领域直接进论证分析）。
- **结构落点**：**必填**。列出本条锚点被乙轨哪些节引用（如 §5、§7-R2、§11-POC1）。这一字段是双轨绑定的证据；若一条锚点在任何乙轨节都用不上，说明它可能不必入选——但若它含关键定义或数据，仍须保留并把落点写为"§12 依据"或"备用引语库"。

### 14.3.2 摘要的特殊规则（用户最常提的要求）

摘要**不是**"挑关键段落"，而是**整段读完、逐段领读**：
1. 先数清摘要共几段（多数期刊摘要为 1 段，部分为结构化摘要 4–5 段）。段数记为 `N`。
2. 输出 `A-01 … A-N`，一条不缺。单段超长摘要按语义转折切为 `A-01a/A-01b`，须注明"同一段内切分"。
3. 摘要里出现的 ROF 方向、样本量、关键数字、核心概念，逐字抄录，不得四舍五入、不得省略星号与括号。
4. 摘要与正文的**不一致处**（摘要宣称的发现强于正文证据、样本量前后不同）必须点出——这是最有价值的阅读产出之一，归入乙轨 §12 与 §17 待核清单。

### 14.3.3 正文关键段落的挑选（沿用 ch 全文领读协议，此处只补执行细则）

五大结构部分逐一覆盖、不得整节跳过；挑选标准是"不遗漏影响理解的知识点"，含关键定义、关键数据、关键转折的短段同样入选。原文缺某部分（如理论文章无实证分析）→ 在甲轨该部分位置写一行「**（原文无此部分）**」，并计入自查表。

**入选段数与配比参考**（防止"只挑两段就交差"）：

| 文献篇幅 | 甲轨最少锚点数 | 说明 |
|---|---|---|
| ≤ 8 页（短文/通讯） | 摘要全读 + 每部分 ≥1 段，合计 ≥ 8 条 | 引言的 GAP 段与结论的贡献段不可缺 |
| 9–20 页（标准期刊论文） | 摘要全读 + 每部分 ≥2 段，合计 ≥ 12 条 | 方法部分须含"变量/编码如何操作化"的段落 |
| 21–40 页 | 摘要全读 + 每部分 ≥3 段，合计 ≥ 18 条 | 须含图表文字解读与稳健性/反例段 |
| > 40 页 / 专著 | 按 ch08 分章处理，**每章**≥2 段 | 目录级覆盖自查，逐章点名 |

此表是**下限**不是上限；以"不遗漏知识点"为准，宁多勿少。

## 14.4 乙轨：结构化报告（16 节骨架，索引式填写）

### 14.4.1 核心规则：短格 + 回指

乙轨**不重复抄原文**（原文只在甲轨出现一次）。每格写法：

> `关键主张：文化创伤是集体记忆的建构过程而非事件本身 →[L-02, p.305]`

- 允许引用 ≤ 15 字的醒目短语以便表格可读，超过 15 字一律改为回指。
- 每个内容格**必须**带 `→[PID]`；确实无文本依据的格写"无文本内依据"并说明（不得留空、不得编造）。
- 表格类节（§5 五要素表、§10 术语表、§11 资产表、§16 自查表）在"位置"列统一填 PID。

### 14.4.2 反向覆盖门（本章的关键机制）

填写乙轨时执行下列检查，任一触发即**回到甲轨补写领读**：

| 触发情形 | 必须做的动作 |
|---|---|
| 某节要写内容，却找不到对应 PID | 回原文找该内容所在段落 → 补领读 → 再回来填 |
| 某格写了内容但没有 PID（"我记得文中说过"） | 立刻回原文定位；定不到 → 删该内容或标 `[待核]` |
| 乙轨引用了不存在的 PID | 悬空指针，必须修正（违规） |
| 摘要宣称的发现找不到对应 ROF 锚点 | 记入 §12／§17，并如实写"正文未找到对应证据" |

这条门使"结构化"不再能绕过"通读"：**结构化的完整性由领读的覆盖度支撑**。

## 14.5 交付总结构（一次输出，五部固定顺序）

```
# 精读报告：<文献标题>

## 第〇部　导读层（文档外信息，统一标注核实状态）
　　0.1 导语（知识网络定位 + 作者知识谱系）
　　0.2 画像卡

## 第一部　甲轨·逐段领读（本报告的唯一原文出处）
　　A. 摘要（A-01 … A-N，全读）
　　I. 引言 → L. 文献回顾 → M. 研究设计 → R. 实证分析 → D. 讨论与结论
　　（各部分内按原文顺序排列锚点；原文无的部分写"（原文无此部分）"）

## 第二部　乙轨·结构化报告（索引式，16 节；每格回指第一部 PID）
　　1 文献身份卡｜2 核心主张｜3 研究问题结构｜4 文献对话位置｜5 论证五要素表
　　6 数据与方法｜7 发现逐条｜8 与既有文献关系｜9 局限与 RFW｜10 术语对照
　　11 对我可用的资产｜12 依据文本内的推论｜13 可引用原句库｜14 800 字提炼
　　15 思考问题｜16 覆盖自查表

## 第三部　桥表·RCOS 阅读密码整合表（PID × 密码 × 部分 × 落点）

## 第四部　收尾
　　17 待核清单｜18 双轨齐备自查表
```

**顺序锁定**：甲轨必在乙轨之前。不得先给结构化结论再补原文——先结论后证据会诱导"结论先行、证据回溯性拼贴"，是零幻觉最容易被破坏的路径。

## 14.6 模式 × 轨道矩阵（防止"切换"式互斥）

| 用户怎么说 | 甲轨（逐段领读） | 乙轨（结构化） | 附加 |
|---|---|---|---|
| "带我通读摘要和关键段落" | **必出**（摘要全读 + 正文关键段） | **必出**（16 节全量） | — |
| "输出结构化结果 / 精读报告 / 拆解这篇" | **必出** | **必出**（16 节全量） | — |
| "通读 + 结构化"（明确要两者） | **必出** | **必出** | 即默认形态，无需特别处理 |
| "评审 / 审稿 / 打分 / 研判质量" | **证据段领读**：每条批评须配原文引语+位置+PID | 评审报告（ch13 §13.6.2 骨架） | 见 14.6.1 |
| "只看方法 / 只回答某问题" | 只领读相关部分（须声明省略了哪些部分） | 只填相关节（其余写"本册未涉及"） | 声明不可省 |
| "只要结论不要原文" | 可省，但**报告首行须写**"应你要求，本次仅出乙轨，无甲轨原文" | 必出 | 用户明确要求才可省 |

**铁则**：除最后一行（用户明确要求"只要结论"）外，任何情况下缺一轨即视为未完成交付。**不得由助手自行判断"这次只给结构就够了"**——那正是旧版不稳定的根因。

### 14.6.1 评审模式是叠加，不是替换

评审/打分 = 乙轨换成 ch13 评审骨架 + 甲轨降为"证据段领读"（每条来自框架的批评都必须挂到具体段落，写 `→[R-05, p.815]`），**不是**取消原文引证。评审结论没有段落锚点，等于没有证据的判词——这既违背铁律一，也无法让用户复核。

## 14.7 长文档分册交付（防"太长所以砍掉一轨"）

一次输出容纳不下时，**分册**，不得砍轨。

1. **分册前先出"分册计划表"**：列明每册包含的锚点区间（如 册一 A-01…I-05；册二 L-01…M-04；册三 R-01…D-06），一次给全。
2. **每册末尾必附**：
   - 本册 PID 台账（已领读 PID 清单 + 尚未领读 PID 清单）
   - 乙轨**增量表**（本册新增可填的节与格）
3. **最后一册**必须给：完整乙轨（合并全册）+ 第三部桥表 + 第四部收尾（待核清单 + 双轨齐备自查表）。
4. **最小可交付单元（MDU）**：任何一次交互至少完成「导语 + A 轨摘要全读 + 依赖摘要的乙轨节 + 分册计划表」。不允许交一个"什么都还没开始"的目录页。
5. **禁止事项**：禁止把"节选版""预览版""示例版"当完整报告交付；禁止把"余下部分下次再补"作为收尾（要么当场进下一册，要么明确列出分册计划）。

## 14.8 三种伪双轨（必须自查排除）

| 伪形态 | 表现 | 判定 |
|---|---|---|
| **摘要充数型** | 甲轨只有摘要 A 轨，正文一句未领读，乙轨却写满 16 节 | 伪：正文结论无锚点支撑 |
| **结论空转型** | 乙轨用概括句代替回指，甲轨只挑 2–3 段 | 伪：反向覆盖门未执行 |
| **缺译型** | 甲轨给原文与解析，省掉完整译文（或摘要式翻译） | 伪：三段式不完整 |

| # | 检查项 | 判定标准 | 结果 |
|---|---|---|---|
| 1 | 摘要覆盖 | 摘要段数 N = 已领读 A 轨条数；差 0 | |
| 2 | 正文覆盖 | I/L/M/R/D 五部分各 ≥1 段（或已注明"原文无此部分"） | |
| 3 | 锚点数达标 | 达到 14.3.3 对应篇幅下限 | |

| 6 | 回指率 | 乙轨内容格带 PID 的比例 = 100%；无 PID 的格数 = 0 | |
| 7 | 无孤儿锚点 | 每条甲轨锚点都在乙轨或桥表出现过（孤儿数 = 0；否则说明理由） | |
| 8 | 无悬空指针 | 乙轨引用的 PID 均真实存在（悬空数 = 0） | |

| 10 | 顺序锁定 | 甲轨位于乙轨之前 | |

## 14.10 与既有铁律的关系

- 双轨不放松任何铁律：零幻觉在甲轨（引语逐字）与乙轨（回指可回溯）两侧同时加强——**回指本身就是可核验性**。
- 甲轨的"解析"字段允许方法论层面的判断，但不允许引入文档外文献、不揣测作者动机（铁律一）。
- 乙轨 §0／§10 源流／§11 对接列属导读层，受铁律四约束（核实、标注、不编造）。
- 长文档分册不构成"信息无损"的例外：未领读的段落必须在 PID 台账中显式列出，不得含混为"其余部分另有论述"。
